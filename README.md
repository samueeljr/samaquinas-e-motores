## Sobre o projeto

O **SA Máquinas e Motores** é um website desenvolvido com o objetivo de criar uma presença digital para a empresa, permitindo apresentar seus produtos e serviços de forma organizada, moderna e intuitiva.

O projeto possui foco em máquinas e equipamentos, incluindo produtos como motosserras, roçadeiras e equipamentos agrícolas.

## Objetivos

- Desenvolver uma interface moderna e responsiva.
- Organizar e apresentar os produtos da empresa.
- Facilitar a navegação e o acesso às informações.
- Aplicar conhecimentos de desenvolvimento web.
- Praticar versionamento e organização de código utilizando Git e GitHub.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Desenvolvimento

O projeto está sendo desenvolvido utilizando tecnologias web fundamentais, sem a utilização de frameworks como React, Vue ou Angular.

Durante o desenvolvimento são aplicados conceitos de:

- Estruturação de páginas com HTML.
- Estilização e responsividade com CSS.
- Manipulação de elementos e interações com JavaScript.
- Organização de arquivos e código.
- Versionamento utilizando Git.

## Status do projeto

**Em desenvolvimento**

Novas funcionalidades, melhorias visuais e ajustes serão adicionados conforme o desenvolvimento do projeto avança.
