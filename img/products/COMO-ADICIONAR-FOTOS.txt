COMO ADICIONAR AS FOTOS DOS PRODUTOS
=====================================

Basta salvar as fotos nesta pasta (img/products/) usando o nome de
arquivo exato de cada produto. O site detecta a foto automaticamente
— não precisa editar nenhum código.

Se um arquivo não existir, o site continua mostrando o ícone de
placeholder no lugar, então nada quebra enquanto você não tiver
todas as fotos prontas. Pode subir uma de cada vez.

RECOMENDAÇÕES DA FOTO
----------------------
- Formato: .jpg
- Proporção: quadrada ou 4:3 (o site corta automaticamente para caber)
- Tamanho sugerido: pelo menos 800x800px
- Fundo neutro/branco combina melhor com o visual do site

QUER USAR .PNG OU OUTRO NOME?
------------------------------
Se preferir, abra js/data.js e troque o valor de "image" do produto,
por exemplo:
  { id:'p01', image:'p01.jpg', ... }
para
  { id:'p01', image:'rocadeira-122c.png', ... }
